🧮 LaTeX:
بالتأكيد، إليك التحويل الدقيق للنص والمعادلات إلى LaTeX. ملاحظة: يتطلب هذا الكود استخدام محرك TeX يدعم Unicode والخطوط مثل `XeLaTeX` أو `LuaLaTeX` لتجميع المستند بشكل صحيح للغة العربية.

```latex
\documentclass[12pt, a4paper]{article}

% Required packages for Arabic support and font selection
\usepackage{fontspec} % For selecting system fonts
\usepackage{polyglossia} % For multi-lingual support, especially right-to-left languages

% Set the main language to Arabic
\setmainlanguage{arabic}
% Choose an Arabic font available on your system. Amiri is a good open-source choice.
% You might need to install this font on your system if you don't have it.
\newfontfamily\arabicfont[Script=Arabic]{Amiri} % Or try "Scheherazade", "Noto Naskh Arabic", etc.

% For the checkmark symbol (✓)
\usepackage{amssymb} % Provides \checkmark

% Optional: Adjust paragraph spacing for better readability
\usepackage{parskip}

% For mathematical environments and symbols
\usepackage{amsmath} % Provides environments like align, gather, etc., and text inside math

\begin{document}

% Set the text direction to right-to-left for the main content
% polyglossia usually handles this automatically for arabic language,
% but explicitly setting \raggedright can ensure consistent alignment if needed.
\raggedright

\section*{جديدنا} % Our New

\subsection*{إضافات و أساسيات النماذج} % Additions & Model Fundamentals

\vspace{0.5cm} % Add some vertical space for separation

\section*{تأسيسك يبدأ} % Your Foundation Begins

\subsection*{التأسيس} % The Foundation

\begin{itemize}
    \item[\checkmark] إصدارات عماد من النماذج
    \item[\checkmark] الصيغ الجديدة لنماذج
    \item[\checkmark] شاملة كل التغيرات في
\end{itemize}

\vspace{0.5cm}

\section*{جديدنا} % Our New (Second instance)

\subsection*{باقات التدريب متدرجة} % Tiered Training Packages

\subsubsection*{للتدريب على نظام اختبار} % For Training on an Exam System

\subsubsection*{لكل باب باقة تدريب خاص} % A Special Training Package for Each Chapter

\vspace{1cm}

% Since the original text didn't contain specific mathematical expressions,
% I'm providing an example section demonstrating how to use the requested formats.
\section*{مثال على التنسيقات الرياضية المطلوبة} % Example of Required Mathematical Formats

هنا بعض الأمثلة على كيفية استخدام تنسيقات LaTeX للتعابير الرياضية:

\begin{itemize}
    \item \textbf{الكسور:} تُكتب $\frac{a}{b}$ باستخدام \texttt{\textbackslash frac\{a\}\{b\}}.
    \item \textbf{الجذور التربيعية:} تُكتب $\sqrt{x^2 + y^2}$ باستخدام \texttt{\textbackslash sqrt\{x\textasciicircum 2 + y\textasciicircum 2\}}.
    \item \textbf{الأسس:} $x^2$ تُكتب باستخدام \texttt{x\textasciicircum 2}.
    \item \textbf{المساواة:} $E = mc^2$ تُكتب باستخدام \texttt{E=mc\textasciicircum 2}.
    \item \textbf{المقارنات:} $a < b$ و $c > d$ تُكتب باستخدام \texttt{a < b} و \texttt{c > d}.
\end{itemize}

ويمكن دمجها في معادلات أكثر تعقيداً، مثلاً:
\[
\text{المعادلة: } f(x) = \frac{\sqrt{x^2+1}}{2x} \quad \text{حيث } x > 0
\]
يتم كتابة هذه المعادلة ضمن بيئة العرض (display math) باستخدام:
\begin{verbatim}
\[
\text{المعادلة: } f(x) = \frac{\sqrt{x^2+1}}{2x} \quad \text{حيث } x > 0
\]
\end{verbatim}

\end{document}
```

**كيفية تجميع هذا الكود:**

1.  **احفظ الملف:** احفظ الكود أعلاه كملف `مثال.tex` (أو أي اسم تختاره مع امتداد `.tex`).
2.  **استخدم XeLaTeX أو LuaLaTeX:** افتح محطة الأوامر (Command Prompt أو Terminal) وانتقل إلى المجلد الذي حفظت فيه الملف. ثم قم بتشغيل أحد الأمرين التاليين:
    *   `xelatex مثال.tex`
    *   `lualatex مثال.tex`
3.  **الخطوط:** تأكد من أن الخط الذي اخترته (في هذا المثال `Amiri`) مثبت على نظامك، وإلا سيقوم LaTeX بالإبلاغ عن خطأ أو استخدام خط افتراضي. يمكنك تغيير `Amiri` إلى أي خط عربي آخر لديك (مثل `Arial` أو `Scheherazade` أو `Noto Naskh Arabic`).

سينتج عن ذلك ملف PDF يحتوي على النص العربي منسقاً بشكل صحيح مع الأمثلة الرياضية.
