بالتأكيد، إليك المعادلات والتعابير الرياضية محوّلة إلى LaTeX بدقة:

1.  **ص = 2س + 5**
    ```latex
    $$y = 2x + 5$$
    ```

2.  **س^2 + ص^2 = ع^2**
    ```latex
    $$x^2 + y^2 = z^2$$
    ```

3.  **الجذر التربيعي لـ س + ص**
    ```latex
    $$\sqrt{x + y}$$
    ```

4.  **2 (أ + ب) = 2أ + 2ب**
    ```latex
    $$2(a + b) = 2a + 2b$$
    ```

5.  **س على ص**
    ```latex
    $$\frac{x}{y}$$
    ```

6.  **مساحة الدائرة = باي * نق^2**
    *(ملاحظة: "نق" عادة ما يُرمز له بـ r في الرياضيات، و "باي" بـ $\pi$)*
    ```latex
    $$A = \pi r^2$$
    ```

7.  **أكبر من، أصغر من، يساوي**
    ```latex
    $$x > y$$
    $$a < b$$
    $$p = q$$
    ```
    *(أو يمكن دمجها كأمثلة ضمن نص: `$x > y$`, `$a < b$`, `$p = q$`)*

8.  **3س + 4ص < 10**
    ```latex
    $$3x + 4y < 10$$
    ```

9.  **س لا يساوي 5**
    ```latex
    $$x \ne 5$$
    ```

10. **الجذر التكعيبي لـ 8**
    ```latex
    $$\sqrt[3]{8}$$
    ```

11. **نص (ق1 + ق2) ع**
    *(ملاحظة: "ق1" و "ق2" عادة ما يرمزان للقاعدة الأولى والثانية، و "ع" للارتفاع، لذا نستخدم subscripts و h)*
    ```latex
    $$\frac{1}{2}(q_1 + q_2)h$$
    ```

12. **أ + ب / ج**
    *(ملاحظة: حسب ترتيب العمليات، هذا يعني أ + (ب مقسومة على ج). إذا كان المقصود (أ + ب) مقسومة على ج، يجب استخدام الأقواس)*
    ```latex
    $$a + \frac{b}{c}$$
    ```
    *(إذا كان المقصود: (أ + ب) / ج، فسيكون كالتالي:)*
    ```latex
    $$\frac{a + b}{c}$$
    ```
