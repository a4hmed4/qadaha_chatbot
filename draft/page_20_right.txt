🧮 LaTeX:
بالتأكيد! يرجى تزويدي بالمعادلات والتعابير الرياضية التي ترغب في تحويلها إلى LaTeX.

سأقدم لك أمثلة على كيفية تحويل بعض التعابير الشائعة، وبعدها يمكنك تزويدي بتعابيرك الخاصة:

**أمثلة:**

1.  **المعادلة الخطية:**
    `2x + 3y = 7`
    التحويل إلى LaTeX:
    ```latex
    \[ 2x + 3y = 7 \]
    ```

2.  **الكسور:**
    `(a + b) / c`
    التحويل إلى LaTeX:
    ```latex
    \[ \frac{a + b}{c} \]
    ```

3.  **الجذر التربيعي:**
    `sqrt(x^2 + y^2)`
    التحويل إلى LaTeX:
    ```latex
    \[ \sqrt{x^2 + y^2} \]
    ```

4.  **الأسس:**
    `e^(ix)`
    التحويل إلى LaTeX:
    ```latex
    \[ e^{ix} \]
    ```

5.  **المعادلة التربيعية:**
    `x = (-b ± sqrt(b^2 - 4ac)) / 2a`
    التحويل إلى LaTeX:
    ```latex
    \[ x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a} \]
    ```

6.  **المتباينات:**
    `x < y`
    التحويل إلى LaTeX:
    ```latex
    \[ x < y \]
    ```
    `a >= b`
    التحويل إلى LaTeX:
    ```latex
    \[ a \ge b \]
    ```
    (يمكنك أيضاً استخدام `\geq`)

7.  **المجموع (Summation):**
    `Sum from i=1 to n of i^2`
    التحويل إلى LaTeX:
    ```latex
    \[ \sum_{i=1}^{n} i^2 \]
    ```

8.  **النهايات (Limits):**
    `Limit as x approaches 0 of sin(x)/x = 1`
    التحويل إلى LaTeX:
    ```latex
    \[ \lim_{x \to 0} \frac{\sin(x)}{x} = 1 \]
    ```

9.  **المشتقات (Derivatives):**
    `df/dx`
    التحويل إلى LaTeX:
    ```latex
    \[ \frac{df}{dx} \]
    ```

**ملاحظات هامة:**

*   **وضع الرياضيات (Math Mode):** يجب أن تكون كل المعادلات والتعابير الرياضية داخل بيئة رياضية في LaTeX. الطريقة الأكثر شيوعاً هي استخدام `\[ \]` للمعادلات المعروضة (display mode) أو `$` `$` للمعادلات داخل النص (inline mode).
*   **الأقواس المعقوفة `{}`:** تُستخدم لتجميع المحتوى. على سبيل المثال، في `e^{ix}`، الأقواس حول `ix` ضرورية لتطبيق الأس على كلا الحرفين.
*   **الوظائف القياسية:** وظائف مثل `sin`, `cos`, `log`, `lim` يجب أن تُكتب باستخدام علامة `\` قبلها (`\sin`, `\cos`, `\log`, `\lim`) لتظهر بشكل صحيح (بخط مائل غير رياضي ومسافة صحيحة).

الآن، يرجى تزويدي بالتعابير التي ترغب في تحويلها!
