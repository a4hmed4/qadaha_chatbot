🧮 LaTeX:
لتحويل النصوص الرياضية إلى LaTeX بدقة، يجب استخدام الحزم المناسبة للغة العربية وتنسيق الجداول. بما أن النص عبارة عن قائمة مواضيع وأرقام صفحات، فإن بيئة `tabular` هي الأنسب.

ملاحظات:
*   لاستخدام اللغة العربية في LaTeX، ستحتاج إلى مترجم يدعم UTF-8 مثل `XeLaTeX` أو `LuaLaTeX`.
*   سنستخدم حزمة `polyglossia` للتحكم في اللغة وتوجيه النص.
*   الأرقام في النص الأصلي هي أرقام عربية، وسيتم الحفاظ عليها تلقائيًا بواسطة `polyglossia`.
*   الرموز الرياضية مثل `\frac{}{}`, `\sqrt{}`, `^2`, `=, <, >` غير موجودة في النص الذي قدمته، لذا لم يتم استخدامها. تم ذكرها في سؤالك كأمثلة على التنسيقات التي قد تحتاجها، ولكنها ليست جزءًا من المحتوى الحالي.

إليك الكود:

```latex
\documentclass{article}
\usepackage{fontspec} % Required for XeLaTeX or LuaLaTeX to use system fonts
\usepackage{polyglossia} % For multilingual support, including Arabic

% Set Arabic as the main language

\setotherlanguage{english} % Optional: if you need to switch to English text

% Choose a suitable Arabic font. Make sure this font is installed on your system.
% Examples: Amiri, Noto Naskh Arabic, Scheherazade, etc.
\setarabicfont{Amiri} % You might need to change this to a font available on your system

\usepackage{amsmath} % For mathematical environments and symbols, good practice even if not used directly here
\usepackage{amssymb} % For additional math symbols

\begin{document}

\section*{\textarabic{قوانين ما قبل التأسيس}} % عنوان غير مرقم

\begin{center} % لتوسيط الجدول
\begin{tabular}{|r|r|} % r|r تعني عمودين محاذاة لليمين مع خط فاصل رأسي

\hline % خط فاصل بين الرؤوس والبيانات
```
