# المساعد التعليمي الذكي - مؤسسة قدها 🎓

هذا هو الجزء الأمامي (Frontend) من تطبيق المساعد التعليمي الذكي المطور خصيصاً لمؤسسة قدها التعليمية في المملكة العربية السعودية.

## 🎯 المميزات

- **واجهة مستخدم حديثة وجذابة** - تصميم عصري باستخدام Material-UI
- **دعم كامل للغة العربية** - واجهة باللغة العربية مع خط Cairo
- **تصميم متجاوب** - يعمل على جميع الأجهزة (الهواتف، الأجهزة اللوحية، الحواسيب)
- **محادثة تفاعلية** - واجهة محادثة سهلة الاستخدام مع المساعد الذكي
- **واجهة تعليمية متخصصة** - مناسبة للطلاب والمعلمين في مؤسسة قدها
- **إدارة المحادثات** - إمكانية مسح المحادثة وبدء محادثة جديدة
- **أسئلة مقترحة** - أسئلة جاهزة للمساعدة في بدء المحادثة

## 🛠️ التقنيات المستخدمة

- **React 18** - مكتبة واجهة المستخدم
- **Material-UI (MUI)** - مكونات واجهة المستخدم
- **Axios** - مكتبة HTTP للاتصال بالـ API
- **خط Cairo العربي** - خط عربي جميل ومناسب

## 📦 التثبيت والتشغيل

### المتطلبات الأساسية
- Node.js (الإصدار 16 أو أحدث)
- npm أو yarn

### خطوات التثبيت

1. **تأكد من تشغيل الـ backend أولاً:**
```bash
cd ..
python app.py
```

2. **قم بتثبيت التبعيات:**
```bash
npm install
```

3. **شغل التطبيق في وضع التطوير:**
```bash
npm start
```

4. **افتح المتصفح على العنوان:**
```
http://localhost:3000
```

## 🏗️ البناء للإنتاج

```bash
npm run build
```

## 🔧 الإعدادات

### الاتصال بالـ Backend
التطبيق يتصل بالـ backend على العنوان `http://localhost:5000` من خلال الـ proxy المحدد في `package.json`.

### تخصيص الألوان
يمكنك تخصيص ألوان التطبيق من خلال تعديل الثيم في `App.js`:

```javascript
const theme = createTheme({
  palette: {
    primary: {
      main: '#1e40af', // اللون الأساسي لمؤسسة قدها
    },
    secondary: {
      main: '#059669', // اللون الثانوي
    },
  },
});
```

## 🎨 المميزات البصرية

### الألوان
- **أزرق غامق** (#1e40af) - اللون الأساسي لمؤسسة قدها
- **أخضر** (#059669) - اللون الثانوي للتعليم
- **أبيض** (#ffffff) - خلفية البطاقات
- **رمادي فاتح** (#f8fafc) - خلفية المحادثة

### الخطوط
- **خط Cairo** - خط عربي جميل ومناسب للقراءة
- **أحجام مختلفة** - للعناوين والنصوص العادية

### التصميم
- **زوايا مدورة** - تصميم عصري وجذاب
- **ظلال خفيفة** - لإضافة العمق
- **مساحات مناسبة** - لسهولة القراءة والاستخدام
- **تدرجات لونية** - لتحسين المظهر العام

## 📱 الاستجابة للشاشات المختلفة

التطبيق مصمم ليعمل بشكل مثالي على:
- **الهواتف الذكية** (320px - 768px)
- **الأجهزة اللوحية** (768px - 1024px)
- **الحواسيب** (1024px+)

## 🔄 إدارة الحالة

التطبيق يستخدم React Hooks لإدارة الحالة:
- `useState` - لحالة الرسائل والإدخال
- `useEffect` - للتأثيرات الجانبية
- `useRef` - للتمرير التلقائي
