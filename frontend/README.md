# مؤسسة قدها التعليمية - المساعد التعليمي الذكي

## نظرة عامة

هذا هو الفرونت إند للمساعد التعليمي الذكي لمؤسسة قدها التعليمية. يوفر واجهة مستخدم حديثة ومتجاوبة للتفاعل مع النموذج اللغوي المتقدم.

## المميزات

### 🎨 واجهة مستخدم متقدمة
- تصميم عصري ومتجاوب يعمل على جميع الأجهزة
- ألوان مخصصة لمؤسسة قدها التعليمية
- رسوم متحركة سلسة وتأثيرات بصرية جذابة
- دعم كامل للغة العربية

### 💬 تجربة محادثة محسنة
- مؤشر تحميل متقدم مع شريط تقدم
- كشف بطء الاتصال وتنبيه المستخدم
- تنسيق النص مع دعم النص العريض والمائل
- اقتراحات أسئلة ذكية

### 🚀 أداء محسن
- تحميل سريع للصفحات
- ضغط الملفات الثابتة
- تخزين مؤقت ذكي
- تحسين للشبكات البطيئة

### 🔧 قابلية التخصيص
- إعدادات سهلة التعديل
- دعم السمات المختلفة
- تكوين مرن للبيئات المختلفة

## المتطلبات

- Node.js 18 أو أحدث
- npm 9 أو أحدث
- Docker (اختياري للنشر)

## التثبيت والتشغيل

### التطوير المحلي

1. **تثبيت التبعيات:**
```bash
cd frontend
npm install
```

2. **تشغيل خادم التطوير:**
```bash
npm start
```

3. **فتح المتصفح:**
```
http://localhost:3000
```

### النشر باستخدام Docker

1. **بناء الصورة:**
```bash
docker build -f Dockerfile.frontend -t qadaha-frontend .
```

2. **تشغيل الحاوية:**
```bash
docker run -p 80:80 qadaha-frontend
```

### النشر باستخدام Docker Compose

```bash
# من المجلد الجذر للمشروع
docker-compose up -d
```

## التخصيص

### تغيير الألوان

يمكنك تخصيص ألوان التطبيق من خلال تعديل الثيم في `App.js`:

```javascript
const theme = createTheme({
  palette: {
    primary: {
      main: '#1e40af', // اللون الأساسي
      light: '#3b82f6',
      dark: '#1e3a8a',
    },
    secondary: {
      main: '#059669', // اللون الثانوي
      light: '#10b981',
      dark: '#047857',
    },
  },
});
```

### إضافة أسئلة مقترحة

يمكنك تعديل الأسئلة المقترحة في `App.js`:

```javascript
const suggestedQuestions = [
  "كيف أحسب مساحة الدائرة؟",
  "اشرح لي نظرية فيثاغورس",
  // أضف أسئلة جديدة هنا
];
```

## الأداء والتحسين

### تحسين التحميل

- تم تحسين حجم الحزم باستخدام Tree Shaking
- ضغط الملفات الثابتة باستخدام Gzip
- تخزين مؤقت ذكي للملفات الثابتة

### تحسين الشبكة

- كشف بطء الاتصال تلقائياً
- مؤشرات تحميل واضحة
- معالجة الأخطاء المحسنة

## الأمان

- رؤوس أمان مضافة في Nginx
- حماية من XSS و CSRF
- سياسة أمان المحتوى (CSP)

## المراقبة والتتبع

### السجلات

- سجلات Nginx للوصول والأخطاء
- سجلات التطبيق للأحداث المهمة

### الصحة

يمكنك فحص صحة التطبيق عبر:
```
http://localhost/health
```

## استكشاف الأخطاء

### مشاكل شائعة

1. **التطبيق لا يتحمل:**
   - تأكد من تشغيل الباك إند على المنفذ 5000
   - تحقق من إعدادات CORS في الباك إند

2. **مشاكل في التحميل:**
   - تحقق من اتصال الإنترنت
   - راجع سجلات المتصفح للأخطاء

3. **مشاكل في Docker:**
   - تأكد من تثبيت Docker
   - تحقق من المنافذ المتاحة
