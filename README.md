# نظام Math RAG - مساعد الرياضيات الذكي

نظام استرجاع المعلومات المعزز بالتوليد (RAG) المخصص للمسائل الرياضية، يعمل باللغة العربية ويقدم إجابات دقيقة ومفصلة.

## الميزات

- تحليل الاستعلامات الرياضية باللغة العربية
- استرجاع المعلومات ذات الصلة من قاعدة بيانات المستندات
- معالجة السياق لتوفير معلومات متكاملة
- توليد إجابات مفصلة ودقيقة بالعربية
- دعم الأسئلة متعددة الأجزاء
- عرض المعادلات الرياضية بتنسيق LaTeX

## متطلبات النظام

- Python 3.10 أو أحدث
- MongoDB
- Ollama (لتشغيل النماذج اللغوية محلياً)

## التثبيت

### إنشاء بيئة افتراضية

```bash
conda create -n school python=3.10.11
conda activate school
pip install -r .\requirements.txt
```

### تثبيت وتشغيل MongoDB

1. قم بتثبيت MongoDB من [الموقع الرسمي](https://www.mongodb.com/try/download/community)
2. تأكد من تشغيل خدمة MongoDB على المنفذ الافتراضي 27017

### تثبيت وتشغيل Ollama

1. قم بتثبيت Ollama من [الموقع الرسمي](https://ollama.ai/download)
2. قم بتنزيل النموذج المطلوب:
   ```bash
   ollama pull qwen3:8b
   ```

## تشغيل النظام

### معالجة الملفات وتحميلها إلى قاعدة البيانات

```bash
python files_processor.py
```

### تشغيل خادم الويب

```bash
python app.py
```

### اختبار النظام باللغة العربية

```bash
python test_arabic_rag.py
```

## هيكل المشروع

- `app.py`: تطبيق Flask الرئيسي
- `lang_graph.py`: تعريف مخطط سير العمل باستخدام LangGraph
- `query_analyzer.py`: تحليل استعلامات المستخدم
- `document_retriever.py`: استرجاع المستندات ذات الصلة
- `context_processor.py`: معالجة السياق المسترجع
- `response_generator.py`: توليد الإجابات النهائية
- `files_processor.py`: معالجة ملفات النصوص وتحميلها إلى MongoDB
- `test_arabic_rag.py`: اختبار النظام باللغة العربية

## تخصيص النظام

يمكنك تخصيص سلوك النظام من خلال تعديل ملف `config.yaml`:

- تغيير إعدادات الاتصال بـ MongoDB
- تعديل نموذج التضمين المستخدم
- ضبط معلمات الاسترجاع
- تغيير النموذج اللغوي المستخدم
