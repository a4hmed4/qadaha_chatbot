# مؤسسة قدها التعليمية - المساعد التعليمي الذكي 🤖

## نظرة عامة

المساعد التعليمي الذكي لمؤسسة قدها التعليمية هو تطبيق متقدم يجمع بين الذكاء الاصطناعي والتعليم، مصمم خصيصاً لمساعدة الطلاب والمعلمين في المملكة العربية السعودية.

## المميزات الرئيسية

### 🧠 ذكاء اصطناعي متقدم
- نموذج لغوي متطور (Qwen 1.5 7B)
- فهم عميق للغة العربية
- إجابات دقيقة ومفصلة للمسائل التعليمية
- دعم كامل للمواد الدراسية المختلفة

### 🎨 واجهة مستخدم حديثة
- تصميم عصري ومتجاوب
- دعم كامل للغة العربية
- تجربة مستخدم سلسة وجذابة
- مؤشرات تحميل متقدمة

### 📚 محتوى تعليمي شامل
- حل المسائل الرياضية والعلمية
- شرح المفاهيم التعليمية
- إجابات على الأسئلة الدراسية
- دعم متقدم للتعليم

### 🚀 أداء محسن
- تحميل سريع
- استجابة فورية
- تحسين للشبكات البطيئة
- إدارة ذكية للموارد

## هيكل المشروع

```
qadaha_chatbot/
├── frontend/                 # واجهة المستخدم
│   ├── src/                 # كود المصدر
│   ├── public/              # الملفات العامة
│   ├── Dockerfile.frontend  # ملف Docker للفرونت إند
│   └── nginx.conf          # إعدادات Nginx
├── backend/                  # الخادم الخلفي
│   ├── app.py              # التطبيق الرئيسي
│   ├── models/             # النماذج اللغوية
│   ├── resources/          # الموارد التعليمية
│   └── Dockerfile.backend  # ملف Docker للباك إند
├── docker-compose.yml       # تكوين Docker Compose
└── README.md               # هذا الملف
```

## المتطلبات

### للتنمية المحلية
- Python 3.8+
- Node.js 18+
- npm 9+
- 8GB RAM (للنموذج اللغوي)

### للنشر
- Docker
- Docker Compose
- 4GB RAM كحد أدنى

## التثبيت والتشغيل

### الطريقة الأولى: التطوير المحلي

#### 1. تشغيل الباك إند
```bash
cd backend
pip install -r requirements.txt
python app.py
```

#### 2. تشغيل الفرونت إند
```bash
cd frontend
npm install
npm start
```

### الطريقة الثانية: باستخدام Docker

#### تشغيل كامل المشروع
```bash
docker-compose up -d
```

#### الوصول للتطبيق
- الفرونت إند: http://localhost
- الباك إند: http://localhost:5000

### الطريقة الثالثة: النشر المنفصل

#### بناء وتشغيل الباك إند
```bash
cd backend
docker build -f Dockerfile.backend -t qadaha-backend .
docker run -p 5000:5000 qadaha-backend
```

#### بناء وتشغيل الفرونت إند
```bash
cd frontend
docker build -f Dockerfile.frontend -t qadaha-frontend .
docker run -p 80:80 qadaha-frontend
```

## استكشاف الأخطاء

### مشاكل شائعة

1. **النموذج لا يتحمل**
   - تأكد من توفر الذاكرة الكافية (8GB+)
   - تحقق من تحميل النموذج بشكل صحيح

2. **مشاكل في الاتصال**
   - تأكد من تشغيل الباك إند على المنفذ 5000
   - تحقق من إعدادات CORS

3. **مشاكل في Docker**
   - تأكد من تثبيت Docker
   - تحقق من المنافذ المتاحة
